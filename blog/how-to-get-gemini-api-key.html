How to Get a Free Google Gemini API Key (AI Studio)

By Zubair Hussain · 2026-09-16

Gemini is optional in LeadGen. When a key is present, it filters generated leads for relevance; without it, leads are returned unfiltered.

Get the key

  1. Open Google AI Studio and sign in.
  2. Click Get API key and create one.
  3. Add it to backend/.env as GEMINI_API_KEY.
GEMINI_API_KEY=your_key_here

Free tier

Google AI Studio provides a free tier for the Gemini API suitable for testing and light production. Confirm the current rate limits in AI Studio.
