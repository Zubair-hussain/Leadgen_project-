Apify API Token: Setup Guide (and Adding LinkedIn / Upwork Actors)

By Zubair Hussain · 2026-09-16

Apify powers the “Professional” deep-crawl mode in LeadGen and is the recommended engine for richer, actor-based sources. It is also where optional job sources like LinkedIn and Upwork can be added.

Get your API token

  1. Sign up at console.apify.com/sign-up.
  2. Open Settings → Integrations → API tokens.
  3. Copy the token and add it to backend/.env as APIFY_API_KEY.
APIFY_API_KEY=your_token_here

Using Store actors

Apify’s Store hosts ready-made actors. LeadGen uses a Google Maps actor for business enrichment. You can add other actors for niche sources.

Job sources: LinkedIn & Upwork

To turn LeadGen into a job finder (for example remote roles posted in the last several hours, or new Upwork contracts), pick a dedicated actor from the Apify Store for that site and call it with your token. Configure the actor’s own filters (keywords, remote, posted-within, location).

Important: always review each site’s Terms of Service and the actor’s documentation before scraping. LinkedIn and Upwork restrict automated access; use compliant actors and respect rate limits and robots rules.

Free tier

Apify’s free plan includes a monthly platform-credit allowance that covers light usage. Confirm current limits on the Apify pricing page.
