# Design Handoff

## Objective

Provide enough visual material for a designer or developer to recreate the landing page and application in Figma.

## Assets

| Asset | Purpose |
| --- | --- |
| `figma/assets/cover.svg` | Figma file cover |
| `figma/assets/landing-page-desktop.svg` | Landing page desktop mockup |
| `figma/assets/app-dashboard.svg` | Authenticated app dashboard mockup |
| `figma/assets/mobile-flow.svg` | Mobile responsive flow |
| `figma/assets/component-board.svg` | Component reference board |

## Acceptance Criteria

- Visual assets are present, not only markdown instructions.
- Landing hero includes the same rotating-word concept as `leadgen.html`.
- App handoff covers sidebar, generator form, metrics, table states, and status chips.
- Component board includes buttons, inputs, cards, chips, rows, and alerts.
