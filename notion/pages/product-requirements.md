# Product Requirements

## Objective

Help users discover, verify, and export B2B leads from authenticated workflows while protecting each user's data.

## Scope

| In Scope | Out of Scope |
| --- | --- |
| Lead generation by niche and location | Paid billing workflow |
| Email verification and confidence labels | Full CRM replacement |
| Deliverability checker | Inbox sending automation |
| Owner-scoped lead storage | Shared team workspaces |
| CSV export | Native mobile app |

## Target Users

- Founder or operator validating outbound segments.
- Growth marketer building prospect lists.
- Agency operator checking deliverability and lead quality.

## Success Measurements

| Metric | Target |
| --- | --- |
| Authenticated route coverage | 100% of private routes |
| Lead ownership isolation | 100% scoped queries |
| Backend test coverage | Around 80% or better |
| Frontend test coverage | Around 80% or better |
| Critical setup docs | Present in README and docs folder |

## Acceptance Criteria

- User can sign in and access the dashboard.
- User can generate leads by niche and location.
- User can verify leads and export CSV.
- User can inspect deliverability guidance.
- User only sees leads they own.
- CI checks run lint and tests without deployment.
