# Prototype Flow

## Landing Page Flow

1. Visitor lands on hero.
2. Hero word pill loops through meeting, booking, closing, winning, signing.
3. Visitor scrolls through product sections.
4. Visitor opens lead demo.
5. Demo shows generated lead states.
6. CTA routes to the app/login.

## App Flow

1. User lands on login.
2. User signs in with Google.
3. Dashboard loads.
4. User configures Generator.
5. User starts lead generation.
6. Leads populate in Leads Hub.
7. User verifies/export leads.
8. User checks sender deliverability.
