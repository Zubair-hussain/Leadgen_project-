# Application Spec

## Product App

The app contains:

- Auth gate / login.
- Dashboard shell.
- Generator.
- Leads Hub.
- Verifier.
- Sender / Deliverability.
- Connection status.

## App Shell

Desktop:

- Fixed left sidebar.
- Main content area.
- Top-right connection status.
- Dark/light mode support.

Mobile:

- Top bar.
- Slide-in navigation.
- Single-column content.

## Generator

Inputs:

- Target niche.
- Target location.
- Platform selection.
- Professional deep-search toggle.

States:

- Idle.
- Validating.
- Generating.
- No results.
- Results created.
- Error.

## Leads Hub

Elements:

- Search.
- Export CSV.
- Bulk verify.
- Lead table.
- Verify action.
- Delete action.
- Source link.

## Verifier

Modes:

- Single lookup.
- Batch paste.
- File upload.
- Bulk database audit.

## Sender / Deliverability

Inputs:

- Sender email.
- Subject.
- Sample body.
- Daily volume.
- DKIM selectors.
- Unsubscribe included.

Outputs:

- Inbox risk score.
- Status label.
- Authentication checks.
- Recommendations.
